## 🚀 How to Run Locally

### Option 1: Double Click (Simplest)
Open `index.html` in any browser (Chrome, Edge, Safari, Firefox). Everything works 100% offline!

### Option 2: Run with Node.js Server
Open a terminal in this folder and run:
```bash
node server.js
```
Then visit:
[http://localhost:3000](http://localhost:3000)

## 🌐 How to Publish for Free (So Bori Can Open It on His Phone!)

### Free Option 1: Vercel (Easiest)
1. Go to [vercel.com](https://vercel.com) and sign up for free.
2. Drag and drop this folder (`borish`) onto Vercel.
3. You will immediately get a live link like `https://only-for-my-bori.vercel.app` to send to Bori!

### Free Option 2: Netlify
1. Go to [netlify.com](https://netlify.com) and sign up.
2. Drag and drop this folder onto the Netlify dashboard.
3. Your website is live instantly!

### Free Option 3: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings** > **Pages** and select the `main` branch.
